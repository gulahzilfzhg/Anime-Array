## [1.0.0] — 2026-10-17

First stable release of the project documentation and published site.

### Added

**Platform**

- Twelve-character conversational roleplay roster: Gojo Satoru, Ryomen Sukuna, Naruto Uzumaki, Itachi Uchiha, Madara Uchiha, Obito Uchiha, Monkey D. Luffy, Roronoa Zoro, Son Goku, Prince Vegeta, Eren Yeager and Levi Ackerman
- Otaku AI conversational assistant with two modes — Standard Brain and Character RP
- Eight built-in Otaku AI tools: Recommend Anime, Currently Airing, Mood Match, Anime Search, Character Creator, Anime Quiz, Power Scaling and Philosophy
- AniPick AI recommendation engine, weighted towards titles the reader abandoned as well as titles they loved
- Vision AI anime image generator
- AI Hub directory indexing all four products in one place
- Streaming responses that begin arriving immediately and render progressively rather than appearing all at once after completion
- Conversation sharing as text, export as a file, and shareable image cards
- Saved chat history for signed-in accounts
- Mobile-first layouts across every product

**Documentation and site**

- This repository: README, licence, contribution guide, security policy, code of conduct and changelog
- Published documentation site at [muqeet-1138.github.io/Anime-Array](https://muqeet-1138.github.io/Anime-Array/), built from `docs/`
- Six pages: home, about, products, technology, FAQ and policies
- Structured data throughout: Organization, WebSite, SoftwareApplication, FAQPage, TechArticle, BreadcrumbList, ItemList, AboutPage and CollectionPage
- `sitemap.xml` and `robots.txt`, with AI crawlers explicitly permitted
- Four project guides in `guides/`: brand, content policy, SEO checklist and AI visibility
- Accessibility baseline: semantic structure, keyboard operability, visible focus, WCAG AA contrast, labelled fields, live regions and honoured reduced-motion preferences
- Progressive enhancement: all six pages render and read fully without JavaScript

## Notes on this changelog

### About scope

This changelog records **reader-visible** changes to the platform and to this repository. It deliberately does not record internal infrastructure, deployment or configuration changes, because publishing an inventory of moving parts helps nobody except somebody looking for weaknesses.

### About honesty

Entries are written when something is genuinely live and usable. Roadmap intentions are kept in `Unreleased / Planned` and are clearly marked as intentions rather than commitments. If something is half-finished it does not get a changelog entry, and it does not get a version number.

### About corrections

The character roster, tool descriptions and factual claims in this repository are subject to correction. See [CONTRIBUTING.md](CONTRIBUTING.md#1-corrections) for how to report one — it is the most valuable contribution available and requires no technical skill.

## Versioning

The documentation repository is versioned independently of the platform. A `1.0.1` in this file means the documentation changed, not that a character was added.

Platform changes with no documentation impact are not always listed here. The contact form — https://animearray.site/contact-us/ — is the authoritative route for "does this actually work right now".
